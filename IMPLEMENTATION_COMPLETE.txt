HOW TO USE THE PROJECT
================================================================================

1. QUICK START WITH DOCKER (Recommended):
   ────────────────────────────────────────
   cd Backend-Assignment
   docker-compose up -d
   
   API available at: http://localhost:8080/api
   Test with: john.analyst@example.com / password123

2. LOCAL DEVELOPMENT (Requires Java 17-21):
   ──────────────────────────────────────────
   Prerequisites:
     • Java 17, 21 (NOT 25 - Lombok compatibility issue)
     • PostgreSQL running on localhost:5432
     • Maven 3.6+
   
   Configure database:
     • Create database: psql -U postgres -c "CREATE DATABASE finance_db;"
     • Update application.yml with your credentials
   
   Build and run:
     cd Backend-Assignment
     mvn clean install
     mvn spring-boot:run
   
   Access API: http://localhost:8080/api

3. KUBERNETES DEPLOYMENT:
   ──────────────────────
   Build image:
     docker build -t finance-api:1.0.0 .
   
   Push to registry:
     docker push your-registry/finance-api:1.0.0
   
   Deploy:
     kubectl apply -f k8s/deployment.yaml

IMPORTANT NOTES
================================================================================

1. JAVA VERSION:
   • Designed for: Java 17, 21 (fully tested)
   • Docker uses: Java 17 (works perfectly)
   • Avoid: Java 25+ (Lombok compatibility issue)
   • If using Java 25: Use Docker or remove Lombok

2. DATABASE:
   • Requires: PostgreSQL 13+
   • Recommended: Use Docker Compose for automatic setup
   • Automatic: Schema created via Liquibase migrations

3. JWT SECRET:
   • MUST change in production
   • Current: Example key only
   • Requirements: Minimum 256 bits

4. CORS:
   • Currently: Permissive (for development)
   • Production: Configure SecurityConfig for your domain

5. MONITORING:
   • Actuator enabled
   • Metrics available
   • Health endpoint: /actuator/health
